# Dados da Pesquisa: Plataforma Interativa para Aprendizagem de Modelagem de Banco de Dados

Este repositório complementar contém os dados brutos e anonimizados referentes ao questionário diagnóstico aplicado durante a etapa de concepção e desenvolvimento da ferramenta educacional (descrita na Seção de Metodologia do artigo).

## Conteúdo do Repositório

Para facilitar a conferência e a transparência do processo científico por parte dos avaliadores, os dados coletados foram disponibilizados em dois formatos:

*   **Arquivos .CSV:** Dados brutos tabulados, permitindo a conferência das respostas puras extraídas do instrumento de coleta.
*   **Arquivos .PDF:** Versão estática de leitura rápida, preservando a visualização direta das respostas consolidadas.

## Diretrizes de Anonimização (Double-Blind Review)

Em rigorosa conformidade com as diretrizes de avaliação cega por pares do evento, todas as informações sensíveis e de identificação (tanto dos participantes da pesquisa quanto das pessoas autoras) foram removidas destes documentos. 

O conteúdo aqui presente destina-se exclusivamente à validação empírica dos resultados, da fundamentação das dores da persona e da elaboração dos requisitos da plataforma propostos no artigo.
